# FER-2013 Facial Emotion Recognition

## Project Overview
This project focuses on recognizing human facial emotions using a Convolutional Neural Network (CNN).

The FER-2013 dataset was used to classify facial expressions into seven emotion categories.

## Technologies
- Python
- TensorFlow / Keras
- CNN
- Google Colab
- NumPy
- Matplotlib

## Emotion Categories
1. Angry
2. Disgust
3. Fear
4. Happy
5. Neutral
6. Sad
7. Surprise

## Dataset
FER-2013 dataset containing 7 emotion classes.

- Training data: 28,709 images
- Testing data: 7,178 images
- Total: 35,887 images

## Model Performance

- Test Accuracy: 54.49%
- Test Loss: 1.2469

## Project Workflow
1. Data loading and preprocessing
2. Training and validation split
3. CNN model construction
4. Model training
5. Model evaluation
6. Classification report analysis
